شروط الاستخدام

تاريخ النفاذ: 26 يوليو 2026 · الإصدار 2.0

تنظم هذه الشروط الوصول إلى موقع نيفلا الحالي قبل الإطلاق وإرسال طلبات تسجيل الاهتمام.

١. المشغل وقبول الشروط

تشغّل شركة ميريديان جلو، وهي شركة سعودية مقرها الرياض، هذا الموقع تحت اسم نيفلا. باستخدام الموقع فإنك توافق على هذه الشروط. إذا لم توافق عليها، فلا تستخدم الموقع ولا ترسل أي نموذج.

٢. موقع تعريفي قبل الإطلاق

يعرّف الموقع بمنصة نيفلا المخطط لها ويستقبل طلبات الاهتمام. وهو ليس حالياً سوقاً أو خدمة حسابات أو دفعاً أو اشتراكاً أو استشارات أو خدمة طبية أو أداة تحليل بالذكاء الاصطناعي أو تجربة افتراضية. أوصاف القدرات المخطط لها معلومات أولية وقد تتغير قبل الإطلاق.

٣. تسجيل الاهتمام

إرسال النموذج يسجل الاهتمام فقط. ولا ينشئ تلقائياً حساباً أو حجزاً أو اشتراكاً أو طلب شراء أو شراكة أو وظيفة أو وكالة أو ملفاً مهنياً أو قبول تاجر أو عيادة أو طبيب أو مختص أو عميل. يجوز لشركة ميريديان جلو مراجعة الطلب أو التواصل أو طلب معلومات إضافية أو رفضه أو عدم اتخاذ إجراء إضافي.

٤. عدم نشوء علاقة تجارية

لا ينشئ إرسال النموذج علاقة تجارية ملزمة أو معاملة في سوق إلكتروني. تعتمد أي علاقة مستقبلية على العناية الواجبة والتراخيص السارية والشروط المتفق عليها والقبول الصريح من الأطراف المعنية.

٥. الأهلية ودقة المعلومات

يجب أن يكون عمرك 18 عاماً على الأقل وأن تكون مؤهلاً نظاماً لاستخدام الموقع. يجب أن تكون المعلومات صحيحة وحديثة وذات صلة وتخصك أو مقدمة بتفويض مناسب. لا ترسل بيانات حساسة أو معلومات سرية تخص الغير إلا إذا طلبت عبر قناة آمنة معتمدة.

٦. الاستخدام المسموح

يجوز لك تصفح الموقع ومشاركة روابطه العامة وإرسال طلب اهتمام حقيقي للغرض المخصص. يجب الالتزام بالأنظمة السعودية واحترام حقوق شركة ميريديان جلو والغير.

٧. الاستخدام المحظور

  • إرسال معلومات كاذبة أو مضللة أو غير مشروعة أو منتهكة أو ضارة أو غير مصرح بها.
  • محاولة تجاوز Turnstile أو ضوابط الموافقة أو تحديد المعدل أو التحكم في الوصول أو أي إجراء أمني.
  • الاستخراج الآلي بحجم غير معقول أو إدخال شيفرة ضارة أو تعطيل الموقع أو انتحال صفة الغير أو اختبار الأنظمة دون تصريح كتابي.
  • استخدام محتوى الموقع أو علاماته بما يوحي بتأييد أو شراكة أو ارتباط دون إذن.

٨. الملكية الفكرية

اسم نيفلا وشعاراتها وهويتها البصرية ونصوصها وتخطيطاتها ورسوماتها ومواد الموقع مملوكة لشركة ميريديان جلو أو مرخصة لها وتحميها الأنظمة السارية. لا تنتقل إليك أي ملكية. لا يمنح التصفح الشخصي حق النسخ أو التعديل أو التوزيع أو الاستغلال التجاري.

٩. خدمات وروابط الغير

قد يعتمد الموقع على خدمات للغير أو يرتبط بها، بما في ذلك خدمات Cloudflare الأمنية وقنوات التواصل الخارجية. يخضع الغير لشروطه وإشعارات خصوصيته. تقدم الروابط للتيسير ولا تعني بذاتها التأييد.

١٠. معلومات الجمال والذكاء الاصطناعي والصحة

أي معلومات عن الجمال أو البشرة أو الأدوات الذكية أو الذكاء الاصطناعي أو التوصيات أو التجربة الافتراضية المخطط لها هي معلومات عامة. ولا تعد تشخيصاً أو علاجاً طبياً أو نصيحة سريرية أو ضماناً للنتائج. استشر مختصاً مرخصاً عند وجود مسألة صحية.

١١. استقلال العيادات والمختصين

تظل العيادات والأطباء والتجار والمختصون وغيرهم ممن يشار إليهم كمشاركين محتملين مستقلين ومسؤولين عن تراخيصهم ومؤهلاتهم وتصريحاتهم ومنتجاتهم وخدماتهم وقراراتهم المهنية. لا تعد الإشارة في هذا الموقع تأييداً أو تأكيداً للتفعيل.

١٢. الإتاحة والتغييرات

نسعى لإبقاء الموقع مفيداً وآمناً، لكننا لا نضمن إتاحته دون انقطاع أو أخطاء. يجوز لنا صيانته أو تعليقه أو تغييره أو إزالة أو تحديث محتواه ونماذجه لأسباب تشغيلية أو أمنية أو نظامية أو تجارية مشروعة.

١٣. إخلاء المسؤولية وحدودها

يقدم الموقع على أساس معقول «بحسب الإتاحة» للمعلومات السابقة للإطلاق. وبالقدر الذي يسمح به النظام، لا تتحمل شركة ميريديان جلو الخسائر غير المباشرة أو التبعية الناشئة فقط عن الاعتماد على أوصاف أولية أو أحداث خارجة عن سيطرتها المعقولة. لا تستبعد هذه الشروط مسؤولية لا يجوز استبعادها نظاماً ولا تمس الحقوق الإلزامية في المملكة.

١٤. الخصوصية والأمن

تعالج البيانات وفق سياسة الخصوصية. أنت مسؤول عن استخدام جهاز واتصال آمنين وتجنب البيانات الحساسة غير اللازمة في الحقول الحرة.

١٥. النظام والاختصاص

تخضع هذه الشروط لأنظمة المملكة العربية السعودية. تختص المحاكم أو الجهات المختصة في المملكة بالمنازعات التي لا تحل ودياً، دون إخلال بالحقوق أو الإجراءات الإلزامية السارية.

١٦. التعديلات واللغة والتواصل

قد نحدث الشروط عند تغير الموقع أو المتطلبات. يحدد تاريخ النفاذ ورقم الإصدار النسخة الحالية. أعدت النسختان العربية والإنجليزية لتكونا متسقتين، وعند اختلاف التفسير تسود النسخة العربية بالقدر الذي يسمح به النظام.
